# Unity Junior Programmer Pathway

This repository contains my journey through Unity's Junior Programmer Pathway course, documenting my learning experience as I developed foundational skills in game development with Unity and C# programming.

## 📚 About My Learning Journey

I completed the [Unity Junior Programmer Pathway](https://learn.unity.com/pathway/junior-programmer?version=6.0), a comprehensive course designed for anyone interested in learning to code or obtaining an entry-level Unity role. The pathway built upon my basic knowledge of Unity and guided me through essential programming concepts without requiring advanced math skills.

### Skills I Developed

#### **Application Scripting**
- Built prototypes to explore new concepts
- Mastered controlling code execution with common logic structures
- Implemented appropriate data types in my projects
- Composed scripts that utilize various Unity APIs
- Developed a code style that is efficient and easy to read

#### **Debugging**
- Practiced diagnosing and fixing exceptions
- Solved common compilation errors
- Debugged compilation errors related to Unity's Scripting API

#### **Programming Theory**
- Applied inheritance and polymorphism principles to simplify and make code reusable
- Implemented abstraction and encapsulation principles, including interfaces, to make code more secure and usable
- Practiced object-oriented programming principles to write efficient, organized, and comprehensible code

#### **Application Scripting**

- Implemented data persistence across scenes and user sessions

#### **Programming User Interfaces**
- Created user interfaces

#### **Profiler**
- Learned to use the Profiler to analyze scenes and identify optimization bottlenecks
- Practiced using the CPU profiler in the Profiler window to deduce which script methods use the most CPU time
- Identified and eliminated unnecessary code for code optimization

## 🎮 My Projects

This repository showcases the Unity projects I completed throughout the learning pathway:

### Prototype 1
I programmed a car moving side-to-side on a floating road, trying to avoid (or hit) obstacles. This project introduced me to the Unity editor and workflow while I learned to create C# scripts and do simple programming, as well as switching between two different camera angles.

### Prototype 2 
In this top-down game, I programmed animals stampeding towards the player who must throw food to keep them fed before they run past. This project deepened my understanding of essential programming concepts including if-then statements, random value generation, arrays, collision detection, prefabs, and instantiation. I learned to create a basic game with projectile launching and player maneuvering mechanics.

### Prototype 3
I created a fast-paced endless side-scrolling runner where the player times jumps over oncoming obstacles to avoid crashing. This project taught me to add music and sound effects, completely transforming the game experience. I also implemented dynamic endless repeating backgrounds and incorporated particle effects like splatters and explosions to make the game more satisfying to play.

### Prototype 4
In this arcade-style Sumo battle, I programmed gameplay where the player knocks increasingly difficult waves of enemies off a floating island using power-ups. This project taught me to implement new gameplay mechanics - programming power-ups that give temporary player advantages and increasingly difficult enemy waves that make survival more challenging, creating a balanced and engaging experience.

### Prototype 5
This is a reflex-testing game where players click to destroy objects randomly tossed in the air before they fall off screen. Here I learned to implement a complete User Interface system, including a title screen with difficulty selection, score tracking, and a game over screen with restart functionality.

### Error Project
A practice project I worked on to improve my debugging and error handling skills in Unity development.

### Manage Scene Flow and Data
In this advanced mission, I learned about data persistence and was introduced to the core pillars of object-oriented programming. The focus was on managing the loading and unloading of data between both scenes and sessions. Throughout this mission, I worked with one practical example that built upon new functionality with each tutorial, ultimately applying everything I learned to build a persistent score system for a small game. This section helped me structure my code more effectively using object-oriented programming principles.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd "Junior Programmer Pathway"
   ```

2. **Open projects in Unity:**
   - Launch Unity Hub
   - Click "Open" and select the desired project folder
   - Ensure you have the compatible Unity version installed

3. **Explore the projects:**
   - Each prototype folder contains a complete Unity project
   - Check the Assets folder for scripts, scenes, and game assets
